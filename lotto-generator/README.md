# 로또 번호 생성기

1~45 사이의 숫자 중 중복 없이 6개를 무작위로 뽑아주는 간단한 웹 프로그램입니다.
빌드나 별도 설치 과정 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 사용법

```bash
# 브라우저에서 바로 열기
open lotto-generator/index.html   # macOS
# 또는 더블클릭으로 실행
```

## 기능

- "게임 수"를 선택해 1 / 5 / 10 게임을 한 번에 생성
- 각 게임은 Fisher–Yates 셔플 알고리즘으로 1~45 중 6개를 중복 없이 추출 후 오름차순 정렬
- 실제 로또 용지처럼 번호 구간별 색상(1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록) 적용

## 참고

실제 로또 추첨 결과와는 무관하며, 재미로 번호를 뽑아보기 위한 도구입니다.
