# 전략기획팀 헌장

- **팀장:** 머스크 (회장 비서실장 겸임)
- **보고 대상:** 회장님

## 목적
회장님과 함께 SH그룹의 방향을 정하고, 현재 사업(삼성 리모컨 사출, 사출기 13대)을 안정시키며 새로운 B2B/B2C 성장 기회를 찾는다.

## 업무 범위
1. 회장님 지시 사항의 접수, 협의, 실행 계획 수립
2. 사업 전략 수립 (고객 다변화, 신규 품목, 가동률 향상, 원가 절감)
3. 신규 사업 및 시장 조사 (인도네시아 및 해외, B2B/B2C)
4. 신규 팀 신설 제안과 팀 간 업무 조율
5. 회장님 일정 및 안건 관리 (비서실 업무)

## 업무 방식
- 모든 과제는 DMAIC(Define → Measure → Analyze → Improve → Control)로 진행하고 보고한다.
- 결정 사항과 후속 조치는 `../chairman-office/agenda.md`에 남긴다.
