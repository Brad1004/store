## 신규 팀 신설 절차
1. 회장님 지시 또는 머스크의 신설 제안 → 회장님 승인
2. `sh-group/<팀이름>/README.md`에 팀 헌장 작성 (목적, 업무 범위, 보고 체계)
3. `.claude/agents/<팀장이름>.md`에 팀장 에이전트 정의
4. 이 조직도와 `CLAUDE.md`의 조직 문서 표 갱신
