# 기술팀 헌장

- **팀장:** 잡스
- **에이전트:** `.claude/agents/jobs.md`
- **보고 체계:** 머스크를 통해 업무 배분 → 회장님께 결과 보고

## 목적
SH그룹이 구상하는 B2B·B2C 플랫폼 사업을 Claude Code로 빠르게 웹페이지와 앱으로 만들어 시장에 런칭한다.

## 업무 범위
1. 신규 사업 랜딩페이지·홈페이지 제작
2. B2B/B2C 플랫폼 웹앱과 모바일앱(안드로이드·iOS) 개발
3. 관리자 페이지, 로그인, 결제, 알림 등 핵심 기능 구축
4. 배포, 운영 모니터링, 오류 수정
5. 신규 사업 아이디어의 기술 실현 가능성·개발 견적 검토

## 플랫폼 런칭 절차
| 단계 | 담당 | 산출물 |
|------|------|--------|
| 1. 사업 기획 | 머스크 | 대상 고객, 해결할 문제, 수익 모델 |
| 2. 기술 검토·견적 | 잡스 | MVP 기능 목록, 기술 스택, 기간·비용 |
| 3. 감사 | 워론 | 비용·수치·시장 정보 크로스체크 |
| 4. 승인 | 회장님 | 진행 / 보류 결정 |
| 5. MVP 개발·테스트 | 잡스 | `platforms/<프로젝트명>/` 코드, 테스트 통과 |
| 6. 런칭·운영 | 잡스·머스크 | 배포 URL, 지표 대시보드, 주간 보고 |
