# 퓨어자카르타 정수기 렌탈 — 랜딩페이지

인도네시아(자카르타·보고르·땅으랑·베카시) 거주 한인 가정을 대상으로 한 정수기 렌탈 서비스의
1페이지 랜딩 웹사이트입니다. 순수 HTML/CSS/JS로 작성되어 빌드 과정 없이 바로 배포할 수 있습니다.

## 구성 파일

- `index.html` — 페이지 전체 마크업 (히어로, 요금제, 후기, FAQ, 신청 폼 등)
- `styles.css` — 스타일시트
- `script.js` — 모바일 메뉴, FAQ 아코디언, 신청 폼 처리 스크립트

## 실행 방법

별도 서버 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
로컬 서버로 띄우려면 예를 들어:

```bash
cd water-purifier-rental
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포 전 꼭 수정해야 할 부분

1. **연락처 정보** — `index.html`에서 아래 항목을 실제 값으로 교체하세요.
   - WhatsApp 링크 2곳: `https://wa.me/6281234567890` → 실제 번호
   - 카카오톡 채널 ID, 이메일 주소 (푸터)
2. **요금제 금액** — `#plans` 섹션의 Rp 금액은 예시 가격입니다. 실제 원가·마진 계산 후 수정하세요.
3. **사업자 정보** — 푸터의 통신판매업 신고번호 등 실제 등록 후 표기하세요.
4. **고객 후기** — `#reviews` 섹션은 예시 후기입니다. 실제 이용 후기로 교체 권장합니다.
5. **신청 폼 연동** — 현재 신청 폼은 브라우저 `localStorage`에만 저장됩니다(데모용).
   실제 운영 시에는 Google Forms, 스프레드시트 연동, 또는 자체 백엔드 API로
   `script.js`의 제출 처리 부분을 교체해야 리드(문의)가 실제로 수신됩니다.

## 운영 체크리스트 (Control 단계 제안)

- 문의 폼 데이터를 매일 확인하고 24시간 이내 회신 SLA 유지
- 월별 신규 계약 수 / 해지(이탈) 건수 트래킹
- 필터 교체 일정 캘린더 관리 및 사전 알림 발송
- 분기별 요금제·경쟁사 가격 재검토
